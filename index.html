❓ あそびかたガイド
① ゲームの目的
  • 右から左へ進んでくる敵を倒して、拠点(左端)を守るゲームです。
  • 敵が拠点に到達するとライフが1減ります。ライフ(最初は20)が0になるとゲームオーバー。
  • 「▶ ウェーブ開始」を押すと敵が出現。ウェーブが進むほど敵のHPが上がり、10ウェーブごとにボスが出ます。
  • 上の「平均敵HP」「最大敵HP」は、そのウェーブの敵のHPです(進行中はそのウェーブ、待機中は次のウェーブ。ボスの回は最大HPがボスのHP)。
  • 敵を倒すとゴールドがもらえます(ボスは5倍)。ゴールドでタワーとオーブを買って強くなりましょう。
② タワーの配置方法

基本の攻撃力と速度です。オーブや進化値でさらに強化されます。
  • 画面右下の3×3のマスをタップして選び、下に出る「建てるタワー」から種類を選ぶと建設できます。
  • ノーマル(30G):バランス型。
  • スピード(50G):攻撃は弱いが超高速。
  • 連結(70G):場にあるほかの連結・鉄塔(連結の効果を持つ)1つごとに、連結と鉄塔の攻撃+25%・速度+15%(インフレ系モードでは+100%ずつ)。連結を何個つなげても、全員が同じ量だけ強くなります。さらに、隣り合う連結以外のタワー1つごとに同じだけ上がります。
  • パワー(60G):遅いが一撃が重い。
  • 鉄塔*(最凶モード限定):ノーマル・スピード・連結・パワーを場に1つずつ建て、進化オーブを1つ持っていると、「合成」欄に鉄塔のボタンが出ます。押すと4タワーが1つの鉄塔になり(いちばん小さい番号のマスに建ちます)、4種すべての効果を持ちます。初期ステータスは攻撃50・毎秒5発。
  • タワーを選ぶと「売却」が出ます(購入額の70%が戻ります)。
  • オーブの効果は全タワーに共通でかかります。
③ オーブの使い方
  • 下の「オーブショップ」でゴールドを使って買います(スピード30G / パワー40G / 進化50G / ボイド200G)。×1・×10・×100で購入数を切り替えられます。
  • 「所持オーブ」のオーブをタップすると、左のオーブ枠(最大4個)に装着されます。枠のオーブをタップすると外せます。
  • スピード:速度+10% / パワー:攻撃+20%
  • メガ:速度・攻撃+20% / ギガ:+80% / ファイナル:+1000%
  • ボイド:7%の確率でダメージ5倍
  • ブラックホール:5%でダメージ100倍、3%で即死
  • 進化オーブ単体には攻撃力アップの効果はなく、進化値を貯めるために使います。
④ オーブの進化(合成)方法
  • 合成は、画面の「合成」欄のボタンで行います。素材が揃ったオーブのボタンだけが表示されます。
  • 素材に使えるのは「所持オーブ」にあるものだけです(枠に入れているオーブは数えません)。
  • メガ:進化+パワー+スピード / ギガ:メガ×3
  • 最終進化:ギガ×3 / 極進化:メガ+ギガ
  • 超進化:進化×2+メガ / 深淵:進化+メガ+ギガ+ボイド
  • ファイナル:最終進化+極進化+超進化+深淵
  • ボイドX:ボイド+進化 / 真空:ボイド×2
  • 突破:ファイナル×3(進化値150以上)
  • ブラックホール:ボイドX+突破+真空+ファイナル(進化値200以上)
  • 最終進化・極進化・超進化・深淵・ボイドX・真空・突破には単体の効果はなく、ファイナルやブラックホールの素材です。
  • 進化値が足りない間は、突破とブラックホールのボタンは出ません。
⑤ 進化値の貯め方
強化 合成解放 ダイヤ
  • オーブ枠4つすべてに「進化」オーブを入れると「★ 4枠進化」ボタンが出ます。押すと進化値+5(枠のオーブは消費)。
  • 進化値は上のステータス欄に表示され、貯まるほど永続で強くなります。
  • 10:範囲攻撃 / 25:オーブ効果+5%
  • 50:強打発生(10%で5倍) / 100:強打率50%
  • 1000:攻撃力×11 / 5000:強打が80倍
  • 9999:攻撃するたび攻撃力+1% / 10000以降:進化値+1ごとにダメージ+10%
  • 画面上部の「10:範囲攻撃 / 25:…」は達成済みだと緑になります。
⑥ ダイヤとダイヤタワー
  • ブラックホールを装着し、進化値が500以上だと、敵を倒すたびに💎を1個獲得。
  • 💎を10個集めたら、オーブ枠の下のダイヤマークをタップするとダイヤタワーが建ちます。
  • ノーマルモードでは、最もHPが高い敵の現在HPの10%を削り続けます。
⑦ モードとセーブ
  • ノーマル:基本ルール。
  • 最凶:インフレーションと同じルールで、敵HPの上昇がさらに激しいモード。体力40から毎ウェーブ2.5倍ずつ上がり(40→100→250…)、同じウェーブの中でも後に出る敵ほど硬くなります。
  • インフレーション:敵HPが毎ウェーブ1.5倍ずつ上昇。ノーマルはレーザー、連結は隣接タワーの数だけ強化、パワーは最初から範囲攻撃、ダイヤタワーは通路で敵を即死させるなど、タワーの性質が変わります。
  • 進行状況は自動保存されます。「中断」でタイトルに戻り、「続きから」で再開できます。
  • 一番下の「テスト」ボタンで進化値を直接設定できます(動作確認用)。「リスタート」で最初からやり直し。
